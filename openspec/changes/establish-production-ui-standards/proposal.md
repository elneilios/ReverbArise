# Proposal

## Why

GitHub issue: [#37](https://github.com/elneilios/ReverbArise/issues/37).
Learn (#11, PR #39) and header navigation (#35, PR #40) now provide an approved
native baseline, but the style guide still describes provisional numbers and
shared UI policies remain partly distributed through screen code. Before Perform
visual work, agents need traceable production standards and practical drift checks.

## What Changes

- Inventory existing tokens, components, consumers and validation gaps; distinguish
  approved production measurements from historical mockups and future suggestions.
- Promote approved Learn/header roles into the existing theme/geometry system and
  authoritative style guide without changing their appearance or interactions.
- Standardise reusable heading, label/helper, empty-state and control policies by
  extending existing helpers/components; retain explicit remaining migration work.
- Document invariant typography, semantic colour, focus and control language plus
  Learn's comfortable profile. Define a review process for compact density without
  inventing Perform values or shrinking type to fit.
- Add scoped styling checks, component/binding regressions and reusable native
  review fixtures; distinguish software renders from Windows DPI and host approval.
- Make reuse, exceptions, versioning and owner acceptance discoverable in agent
  guidance and future UI change plans, without editing generated OpenSpec tooling.

This PR contributes planning only. Follow-on implementation requires a new Apply
request and a separate PR; proposal merge must not close #37.

## Capabilities

### New Capabilities

- `ui-design-system`: traceable production UI standards, shared-pattern ownership,
  controlled density evolution, styling enforcement and visual-change governance.

### Modified Capabilities

None. Existing `swell-workspace` layout, workflow and editing contracts remain
authoritative. The completed `enhance-header-mode-navigation` delta already owns
the regular header-description requirement; this change does not duplicate it.

## Impact

Implementation will affect `Source/UI/WorkspaceTheme.h`, `UiGeometry.h`, selected
`Controls/` helpers and their Learn/header consumers, focused UI tests, a small
repository lint entry point, CMake test registration, the production style guide,
UI development standards, `AGENTS.md` and dated validation evidence. No new package,
whole-plugin migration, Perform redesign, DSP, host parameter, persistent identity
or asset-format change is proposed. See [design.md](design.md) for inventory and
implementation boundaries.
