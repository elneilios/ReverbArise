Reverse Reverb for Creative Swells

ReverbArise turns captured audio into reverse-reverb swells. Capture a phrase in Learn, generate swells, then shape, audition and play them in Perform. Stay in Perform for DAW playback and your DAW's normal render or bounce. Export is optional: use it when you want ReverbArise to create a separate WAV.

1. Install and route your audio

  1. Extract the complete ZIP into a new folder. Keep ReverbArise.vst3 as a whole directory, including its Contents folder. Do not copy only the inner binary.
  2. Close your DAW. If ReverbArise is already installed, preserve the existing bundle somewhere safe for rollback. Do not overwrite an installation during testing. Ask the sender to help if you cannot isolate the test installation.
  3. Follow the setup for your host to make the bundle available and load ReverbArise as an effect on the audio you want to process. Route its output to your normal monitoring path.
  4. Use a copy of a project for alpha testing. Choose a short phrase with clear attacks, set a normal musical tempo, and check that you can hear the dry source through the insert.

This build targets Windows x64 VST3. Ask the sender for the exact host and build acceptance record for this candidate. Clean-machine installation and other hosts remain unverified unless separately recorded.

2. Learn: capture a phrase

The left column has Capture & Generate and Sound tabs. Capture & Generate holds Recapture audio, Detect events, Generate on Stop and Event sensitivity. Sound holds the preset and Level defaults for new swells. It stays available with detection off. Generate and its readiness guidance remain below either tab when automatic swells are enabled.

  1. Select Learn in the header. An empty capture view is normal in a fresh project.
  2. With Loop Mode off, start playback in your DAW and play the phrase through the plugin. Song capture requires DAW playback. The Audition button does not start capture or move your DAW.
  3. Stop the DAW after the phrase. Wait for the source and event analysis to settle before generating. Follow the inline status if capture is still processing or unavailable.

In Learn, the waveform shows newly captured Song audio while playback runs. If Recapture audio is off, regions you've already captured keep their existing waveform.

Song Mode needs bar and beat position, tempo and time signature from the host. If those are unavailable, Learn explains what it needs and hides the playhead. For a setup driven by clock pulses, use Loop Mode.

Recapture audio replaces audio on a later pass when enabled. Leave it off to retain captured audio. Protect your original projects and captured/cache assets; do not delete them to resolve a display or scan problem.

Capture one Loop

Turn on Loop Mode in Source Capture, route stereo audio through ReverbArise, and supply a steady timing source. Use Duration for a set number of Bars or Beats. Click Arm before the downbeat you want to record. With End on Signal, click Arm to request a start and click it again during recording to finish at the next downbeat. Choose End on repeat to record one complete pass. If you arm partway through a pass, recording waits for the next repeat to start. Click Arm again to cancel. See the host appendices for repeat setup.

Before recording starts, switch Arm off to cancel, even if timing is stopped. Switching Arm off or sending Learn Stop cancels a Duration take. For End on Signal, keep timing running through the closing downbeat. A timing interruption before it cancels the take and keeps the prior recording. See Loop signals and examples to sequence Start/Arm and Stop, and the host appendices for how each setup chooses the start.

Recapture Audio off protects an accepted Loop. Turn it on before arming to replace the Loop after a valid take. This applies to both Learn Arm and sequenced Start/Arm. The new waveform grows from the start of the phrase while recording. If the take is cancelled or fails, the previous waveform returns. Detect events and Event sensitivity work on the accepted Loop waveform. Use Generate Swells to build swells from those markers. Generate on Stop is available for Song capture.

3. Inspect markers, then Generate Swells

  1. Keep Detect events enabled for automatic swells. Inspect the waveform and event markers after playback stops. Hover to inspect. Left-click or drag to place an inspection pin. Scroll to zoom at the pointer and press the wheel while dragging to pan. Escape clears the pin when the waveform has focus.
  2. Adjust Event sensitivity to preview fewer stronger attacks or finer event detail. Wait for analysis to update. These markers preview the next generation; they do not yet mean playable swells exist.
  3. Open Sound and choose a Sound Preset and set Level for new swells. Click Generate Swells when it becomes available.
  4. Wait for the resulting swells to render. The initial successful generation opens Perform and selects the first chronological swell. Returning to an existing editing session retains its navigation context.

Generate on Stop is off in new projects. For Song capture, enabling it lets stopping a capture request generation automatically. Supported older projects can restore this preference as on, so check it when opening an old session. Regeneration can replace eligible automatic swells; manual, edited and frozen work has protection. Empty, unchanged or failed generation keeps existing work. For deliberate manual placement, turn detection off and add swells in Perform.

4. Perform: shape, audition and play in your DAW

In Swells, use the arrow keys to select a swell and Tab to reach its Enabled checkbox and More actions. Right-click a row or click its three dots to open the same menu. Select multiple swells, then open the menu on a selected row to delete the group. The menu shows the count and asks for confirmation. Rename is unavailable during multiselect. Delete from an unselected row affects only that row. In the menu, use the arrows to inspect actions, Enter or Space to run an available action, and Escape to close it. In Rename, enter a name and choose OK or press Return. If the name is empty, the dialog shows how to correct it. Choose Cancel or press Escape to discard your draft.

Right-click an inspector knob to see its Reset action. The label tells you whether it returns to the initial position, the default value, or automatic start. The same menu keys work here.

The selected-swell inspector has Timing, Envelope and Sound sections. Timing holds target, placement and source bounds; Envelope holds pre-roll, end offset, fades and curves; Sound holds the selected swell's preset and Level. Reset and Reset All stay below the sections without inspector scrolling. Other settings remain available from the gear button.

For an accepted Song, to set the selected swell's source by whole bars, open Settings → Swell. Enter Bar start and End excl., then choose Set source from bars or press Return in either field. The end bar is excluded, so a start of 4 and an end of 8 use bars 4 through 7. Leaving a field checks the range and shows any error below it. To apply the corrected range, use the button or Return. Selecting a different swell clears both bar fields so you can enter a range for that swell. Unfreeze a frozen swell before changing its source.

In the Perform inspector, press Return or move focus away to apply an exact typed value. A rejected value leaves the last accepted value in place and shows the reason below the field. Press Escape to cancel an edit. Where a number box has stepper arrows, scroll over the box or arrows to change the value one step at a time.

Level adjusts the selected swell relative to its saved starting level. Changing one swell leaves the other swells at their set levels. Turn the dial or type a value from −12 to +12 dB. 0 dB is at 12 o'clock. When you drag across it, a small detent helps you find neutral. Use the wheel or arrow keys for 1 dB steps. Hold Ctrl while scrolling for 0.1 dB steps. Shift also gives fine adjustment on Level. Older projects can show a value below −12 dB in the input. That value stays applied until you edit Level. Press the dial to bring it to −12 dB, or type a valid value to go straight to it. Double-click the dial to reset Level to 0 dB, or right-click for the reset action. Learn's future Level default, Live wet, and Export's Dry/Wet levels are separate controls.

Open Sound Preset to choose directly, or use Previous and Next to cycle through the sounds. Choose Custom IR to reuse a retained file or import WAV or WavPack from the IR File row. Learn sets the sound and Level for future swells. Perform applies edits to the selected swell. The current sound remains active while another response prepares. If preparation exceeds two seconds, the Sound panel shows the request. A failed import explains what to try at the file row. Unfreeze a swell before changing its response.

In Learn or Perform Sound, Level adjusts the wet swell. Damping shortens the response as you turn it up. High Pass and Low Pass filter the captured source feeding the swell, leaving the dry sound alone. Each cut spans 20 Hz to 20 kHz and can be switched Off. Double-click a knob or use its right-click reset. Learn sets the defaults for new swells. In Perform the edits apply to the selected swell.

Choose Stereo Ping Pong Crescendo for alternating echoes that build into the arrival. Turn Tempo Sync on to align them to the plugin ruler's Beat 1 at a compatible fixed tempo. Echo Rate steps through quarter, eighth, dotted eighth, sixteenth, dotted sixteenth and thirty-second notes. Stereo Spread adjusts how far the wet echoes alternate left and right. Gate Amount defaults to 0% for the original echo tails. Turn it up to reduce overlap and make the left/right swaps clearer on sustained sounds. At 100% it uses the tighter version. Damping controls how much the individual echo hits ring. Use 0% for the original response, 50% for moderate damping, and higher values to shorten the ring more aggressively. Build Intensity controls how much the echoes grow into the arrival. At 0% the response hits have even peaks. At 75% they use the original rise, and higher settings make the later hits stronger. Double-click a Sound dial or use its right-click menu to restore its default. Knob values and synced timing handles follow the drag, then the new response prepares after you release. You can keep an off-grid arrival in Perform and let the echoes follow the ruler. Moving a synced swell can prepare a new response, and the gap before the arrival can change by a subdivision. With Sync off, the echoes use the reference tempo and move with the swell.

To review suggested onsets, use Settings → Recovery → Onset suggestions. Choose a sample from the dropdown or select it in the source lane. In the dropdown, use the arrow keys to inspect choices, Return to select, or Escape to dismiss. The choice survives a refresh while the sample remains available. Use Confirm to apply the choice.

  1. Select a swell in the chronological Swells list. The timeline automatically pans and zooms just like Fit, showing the complete swell context. Click the selected row again to return after panning or zooming away. Wait until its render is ready to audition; the inspector shows the selected swell's editable settings.
  2. Stop DAW playback before using Audition. It loops the finite selected listening window until Stop; it does not start the DAW. Starting host playback can interrupt audition.
  3. The listening button shows Dry + wet for captured dry plus wet. Click it to switch to Wet only, and click again to return. Live wet sets the wet audition gain. Audition reports an overload if the mix exceeds full scale. Export has its own blend.
  4. Use the inspector to adjust the selected swell's timing, shape, level and IR. Read the bottom context help for each control. Changes to source audio, the assigned IR or material timing rebuild existing unfrozen sounds automatically, even with Detect events and Generate on Stop off. Fades, curves, level and name reuse the prepared sound. Pure placement also reuses it unless a tempo-synced Ping Pong response needs to realign. Extending beyond captured support needs real source audio.
  5. Choose another IR to try a different sound. The swell keeps its arrival and fits the wet timing to the new response when needed. A longer IR can bring back the original timing. During Audition or Song playback, the previous sound plays while the new one prepares, then hands over at the current position. If the change fails, read the IR status for the cause and what to try next. Unfreeze a frozen swell before changing its IR.
  6. Use Zoom and Fit to inspect the timeline. Scroll over the waveform to zoom at the pointer and press the wheel while dragging to pan. Left-click or drag open waveform to move the local playhead. Drag a handle to edit it. Left-drag the Overview to pan at the current zoom. The local playhead is independent of DAW playback and Audition. Snap follows the chosen musical grid when timing is reliable. Ctrl bypasses Snap; Shift fine-adjusts timing gestures; both can be combined. Exact value entry is available in value fields. Hold Ctrl while scrolling over a dial or track for finer adjustment where its range allows it. On snapped timing dials, Ctrl+wheel moves in small increments between grid points.

Newly generated swells use a short source-edge taper to reduce cut-edge clicks in overlapping swells. Opening a saved project preserves its existing wet renders. To adopt this processing for older unfrozen swells, stay in Perform and use Settings → Recovery → Regenerate all. This forces fresh renders for all eligible swells, including already current ready, disabled and muted swells; Regenerate selected explicitly rerenders only the selection. Frozen swells stay unchanged until you unfreeze and regenerate them, and swells importing an IR are skipped. Feedback directly below the buttons reports how many were queued or skipped, or why nothing was queued. Queued means work was accepted; check each swell's status for completion or errors. Existing captured source is sufficient; no recapture is needed.

Cue a Loop in Perform

After Learn accepts a Loop, generate swells and open Perform. Keep your timing source running and enable Live playback in Settings. Cue Loop becomes available when timing and the swells are ready.

  1. Click Cue Loop at any point while playback is running. Beat one of the Loop lands on the first bar with room for the full lead-in. The captured Loop then repeats at its recorded length. Click Cancel Loop while waiting to cancel the start.
  2. Click Stop Loop to finish the current pass and skip the next lead-in. Click Stop Now while it is finishing for an immediate short fade. With Dry + Wet routing, incoming dry audio continues.
  3. After stopping the transport, seeking, or losing the Clock, restore timing and Cue again. If Cue is disabled, read the status beside it.

Hover over a disabled Audition or Cue Loop button to see why it is unavailable. Both need the host to use the sample rate of the accepted Loop. Set the host to the displayed rate to play the existing capture.

You can edit swells while the Loop plays. Playback keeps its place and switches smoothly to the updated mix as soon as the new render is ready during repeating playback. If you mute every swell, the Loop continues in time so you can bring the wet sound back in.

During Loop playback the yellow playhead follows the current pass in the waveform and Overview. The footer shows the Loop's captured tempo and time signature, and its Bar and Beat follow the playhead. They return to Bar 1, Beat 1 each time the Loop repeats. Position is unavailable until beat one and after stopping. The tinted Lead-In region shows where the next pass starts building. Its faint waveform shows the prepared wet mix that wraps into that region, regardless of which swell you select.

Audition plays the captured dry audio around the selected swell. In Loop Perform, Dry + Wet keeps the incoming dry signal and adds the repeating swells. When ReverbArise generates swells in Song or Loop, it reserves enough headroom to keep the wet mix at or below −1 dBFS at default settings. The check uses the swells that are enabled, unmuted and included by Solo. For Loop it also includes overlaps across the wrap.

In Song and Loop, Dry + Wet adds wet to the original dry signal. A boost or a hot dry signal can push the combined output above 0 dBFS. ReverbArise reports overload and leaves the levels as set. To reduce the wet mix, turn down Live wet in Settings → Playback. To reduce the combined level, adjust gain in your DAW before any stage that clips.

Use the + beside Swells to add a swell at the Loop playhead. When there is no playhead inside the phrase, + adds at the start of the visible loop. Double-click the waveform to choose a different point.

Play and render Song swells through your DAW

  1. Stay in Perform and start your DAW transport. Prepared swells play at their saved song positions independently of the current incoming source audio. Internal Audition is a separate way to inspect a selected listening window.
  2. Open the gear button, then Settings → Playback, to check Live playback, Routing and Live wet. Enable Live playback. Choose Dry + Wet for incoming dry audio plus the prepared wet swells, or Wet Only for the wet swells alone. Set Live wet to suit your mix. Routing here controls DAW playback; the Audition listening button controls internal preview. Live wet also affects Audition's wet gain.
  3. To render the effect with your track or mix, leave ReverbArise in Perform and use your DAW's normal render, bounce or export command. You do not need to enter ReverbArise's Export mode.

Caution: In Perform, swells can remain audible during DAW playback, even if the source is silent or muted. This warning remains in the message bar when no more urgent message is displayed, and returns when that message clears. Its full help explains: “Perform plays prepared swells at saved Song positions, including before notes and through silence. Pattern playback or muting a Playlist track or Channel Rack instrument may not stop them. Bypass the effect or mute its mixer track to stop these swells.” Bypassing can restore dry audio; mixer mute silences the whole mixer path. Neither action deletes captured source or prepared swells. The warning is general guidance, not an indication that the plugin has detected Pattern mode or a muted source.

Watch readiness and inline notices if wet audio is missing. Prepared playback needs compatible song timing and available rendered audio. Export mode bypasses the DAW wet effect while you prepare a separate WAV, so return to Perform for DAW playback or rendering.

Loop control signals and examples

Send control notes to the effect instance on MIDI channel 1. A short note with positive velocity triggers the action when it starts. Keep the control notes on a separate route from any notes that play your instruments. Use the MIDI number as the reference because hosts display octaves differently. A dash means the host has no mapping for that signal.

ReverbArise Loop signal map
SignalMIDI numberRack Note GateFL Studio noteWhat it does
Clock23B0—Supplies one beat per pulse for Learn and Perform. This input uses note events. FL Studio supplies timing through its transport.
Learn Start/Arm24C1C2Arms Learn to capture at the next eligible beat or downbeat.
Learn Stop25C♯1C♯2Finishes End on Signal capture at the next downbeat after the request. Cancels a Duration or End on repeat take.
Phrase12C0C1Sets beat one for future Cues while Loop playback is idle. In Rack Learn, it also marks the repeat boundary for End on repeat when aligned with Clock.
Perform Cue16E0E1Queues the prepared Loop for the first downbeat with room for the full lead-in.
Perform Stop17F0F1Finishes the current pass without the next lead-in, or cancels a queued start.
Perform Stop Now18F♯0F♯1Fades the wet signal immediately, or cancels a queued start.
Reset22A♯0—Clears Rack timing and cancels an in-progress take or Loop playback. Cue again once timing returns.
Bar19G0—Marks bar boundaries for older marker-based patches. In Perform, it can also align an idle Loop if it arrives with Clock.
Beat21A0—Marks beats in the older marker-based route.
Capture Gate14D0—Recognized for older marker-based patches. For sequenced capture, use Learn Start/Arm and Learn Stop. Releasing Capture Gate does not finish an End on Signal take.

For a new setup that sends Clock notes, leave the older Beat and Bar inputs disconnected during Learn. The older marker-based Duration setup uses its own Beat, Bar and recurring Phrase signals.

Capture two bars from a sequence

  1. In Learn, select Loop Mode and End on Signal. Leave the Arm button off. Turn on Recapture Audio only if you want a successful take to replace an accepted Loop.
  2. Start the timing source and play the audio through the effect. Send Learn Start/Arm (24) on beat one of the first bar you want to record.
  3. Send Learn Stop (25) during the second bar, before the next downbeat. Keep timing running through that downbeat. The take closes there and contains two bars.
  4. Once the Loop is accepted, click Generate Swells and open Perform when the swells are ready. The MIDI notes automate recording and playback requests. Generating the swells and choosing Perform are separate steps.

Launch and stop the prepared Loop from a sequence

  1. In Perform, wait for Ready beside Cue Loop. Send Perform Cue (16) far enough ahead of the target downbeat for the longest swell lead-in. If Cue arrives too late, playback waits for a later downbeat.
  2. Send Perform Stop (17) during the final pass you want to hear. The Loop finishes that pass without the next lead-in. For an immediate fade, send Perform Stop Now (18).
  3. To shift the playback grid, send Phrase (12) at the desired beat-one position while playback is idle, then Cue. For example, place Phrase on beat 2 of an earlier bar so the next eligible launch can land on beat 2 of a later bar. Allow room for the lead-in. In Perform, Phrase affects future launches. A queued or playing Loop keeps its current origin.

After a seek, reset or loss of timing, restore the timing source and send a fresh Cue. Resend Phrase first if you want to reestablish a custom playback origin. Use MIDI notes to sequence these actions. ReverbArise currently has no dedicated Loop automation parameters. See the host appendices for the audio and control routing.

5. Optional: Export a WAV directly from ReverbArise

Direct WAV Export currently requires an accepted Song. For an accepted Loop, use Perform playback and DAW rendering.

Export does not automatically attenuate the wet aggregate or combined mix. Float32 WAV preserves samples above 0 dBFS; a peak warning means downstream playback or conversion may clip. Per-swell calibration and shaping still apply. Preview uses the same prepared audio, with short monitoring-only boundary ramps.

Use this mode when you want a separate WAV to place in your DAW or send elsewhere. You can skip it and keep using Perform for playback and DAW rendering, then save your project in step 6.

  1. Select Export. Wait for preparation to complete. Resolve any missing-source or wet-render warnings before relying on the result.
  2. Choose a Mix Character starting point or edit Dry and Wet independently. Each ranges from 0–100%; 100% is unity for that branch. Dry 0% / Wet 100% is wet-only, 100% / 0% is dry-only, and 100% / 100% adds both at full level. Unmatched edits show Custom. At 0% / 0%, preview and WAV delivery are disabled. These levels are independent of Perform's listening switch. Loop Export scales the Perform wet mix, including Live wet.
  3. Use Export's preview Play and Stop to check the prepared mix. While it plays, change Mix Character or Dry/Wet: playback continues from the moving playhead with a short, smooth gain transition. Left-click or drag the waveform to position a ready preview. Scroll to zoom at the pointer and press the wheel while dragging to pan. Use Fit or Home to restore the view. You can still navigate a previous waveform while the new mix prepares. These actions leave the DAW transport alone. Gain edits keep your view; Save and Drag wait for the current WAV. A previous waveform is labelled while its replacement is measured. Stop or 0% / 0% stops playback; later level edits do not start it again.
  4. Use Save WAV to choose a destination, or drag the WAV tile into your DAW or a folder as soon as it is ready. The WAV cursor shows where you can drop it. If you see a stop sign, move to a target that accepts files or use Save WAV. The tile returns to its dotted outline when the drag ends. When layering a dry/wet WAV in the DAW, mute the original source to avoid doubling dry audio; use Dry 0% / Wet 100% for a wet-only layer. Keep your exported WAV separate from the plugin's working cache.

Export a captured Loop

With an accepted Loop and a ready enabled swell, open Export. Export uses the captured Loop's own timing and exact length. It does not need the transport, Clock or Phrase to keep running, and it can be ready while Cue Loop is unavailable. Preview needs an audio device at the captured sample rate; Save and Drag can still deliver the captured-rate WAV when Preview is disabled. Hover over Preview for the reason.

  1. Choose Repeats: the number of Loop passes to include. The first swell lead-in is included once, swells and tails overlap across internal repeat boundaries, and the final scheduled pass keeps its complete tail. There is no extra unscheduled pass.
  2. Choose a Lead-in grid. ReverbArise rounds the WAV start backward to that grid so no initial swell is cut off. The waveform labels WAV start separately from Loop Bar 1. Follow the placement instruction inside the WAV tile. For example, if the earliest wet starts 2.4 bars early and the grid is 4 bars, the file begins 4 bars early with 1.6 bars of silence. To put Loop Bar 1 at project bar 17, place the WAV at bar 13.
  3. Use the same Mix Character and Dry/Wet controls as Song Export. A fresh Loop mix starts at Wet Layer (Dry 0%, Wet 100%). Raising Dry includes the captured dry Loop once per pass in both Preview and the WAV. Dry is silent before the first pass and in the final wet tail. A dry-only WAV starts at Loop Bar 1. At 0% / 0%, Preview and file delivery are disabled.
  4. In Loop Export, Wet 100% uses the swell level from Perform, including its saved starting gains, each swell's Level and Live wet. A different Wet setting scales that level in Preview and the WAV. For Wet Layer, adjust the original dry in your host mixer and check the combined peak there.
  5. Preview, then Save WAV or drag the ready tile. Keep the destination tempo at the captured tempo for the stated bar offset; Export does not stretch the take. Mute or replace the original dry when using a dry-inclusive WAV to avoid doubling it. Song and Loop keep their own mix preferences, and previous exported files remain unchanged.

6. Save, close and reopen safely

Developer-state transition: opening a project with the older single-blend Export preference resets that preference to wet-only and prepares a fresh revision. Previously exported WAVs and their stored history remain intact. Keep your earlier project copy for rollback; do not remove older WAVs already used by your DAW.

  1. Stop internal preview and save a copy of your DAW project. Keep captured source, render/cache assets and any exported WAVs available.
  2. Close and reopen that copy. Check plugin recognition, captured waveform, swell list, settings and playback. Restoring a session does not automatically start audition.
  3. Send the sender any missing-asset or restore warning. Do not rename plugin identities or delete caches as a repair. To roll back, close the DAW, restore the preserved installation and rescan; retain the original project copy and its assets.

Open the gear button, then Settings → Storage, to see this instance's working folder, file counts and disk usage. The page scans automatically when opened. When you return, the last scan stays visible with its timestamp while a fresh scan runs. Stop scan appears only while scanning. Scanning never changes audio or project files. If coverage is incomplete, let capture or rendering settle and reopen the page. Older saved projects may still depend on retained or duplicate audio: these figures do not identify files that are safe to delete.

When you reopen a project with an accepted Loop, Learn opens with Arm and Recapture Audio off. The saved Loop and its swell edits are available when the referenced assets can be verified. To play the swells, open Perform, start your timing source and cue the Loop again. Stop playback before recovering assets. If you moved an associated asset folder, use Locate assets.... To recover from a complete backup, use Restore backup.... You can find both actions in Settings → Storage. Save the host project again after adopting a recovered folder.

Choose folder... prepares and verifies a copy in a dedicated asset folder, for example beside your DAW project. Your working folder stays unchanged until you click Use This Folder. After it succeeds, save the DAW project to retain the association. Original assets stay in place. To make an independent physical copy of an associated project, choose a new empty folder and use the same verified-copy flow. Save As alone never moves assets.

If an associated store moves, Locate assets... verifies its folder before using it. If that store is unavailable, Restore backup... asks for a completed receipt and then an empty destination. If recovery is impossible, Choose recovery folder... can prepare an explicitly incomplete workspace, preserving swell markers, edits, original locators and verified surviving files. It is not a complete copy or backup. After explicitly using it, follow normal Learn with Detect events off and Recapture audio on; existing unfrozen swells rebuild when complete required source and IRs are available. Missing frozen audio requires explicit unfreezing, and lost exported/Playlist files cannot be recreated exactly.

Keep a pre-upgrade DAW project, its original plugin binary and original asset folder. Associated projects use a newer state format that an older binary may reject; rollback uses the retained old project.

The action buttons stay at the bottom while the storage details above them scroll. Back up assets... copies this instance's accepted source, IRs, saved wet results and saved Export history into an empty folder or an existing supported backup. Wait for Backup complete. Pending work, other instances, older FLPs and external Playlist copies are excluded. Save the DAW project and its external audio separately, and back up every plugin instance you need.

Copy the whole backup folder, including its receipts and snapshots. Open the matching DAW project first. Locate assets... selects the original instance asset folder, verifies the expected files and copies them into this instance's user-data folder. Restore backup... selects the exact completed JSON receipt inside the backup's receipts folder, or its containing backup folder when already known. Both preserve conflicting existing files, current swell edits and the working-folder association. Keep original folders and backups.

If expected assets are missing when the editor opens, a modal warning offers Locate or Restore. After successful copying the plugin reloads verified assets; intact compatible saved sounds are reused. The warning also explains normal re-learning: continue to Learn, turn Detect events off and Recapture audio on, play the entire song, then stop and wait. Existing markers and parameters persist. Complete accepted audio and valid assigned IRs rebuild eligible swells automatically; no Generate click is needed. Partial, cancelled or rejected capture retains the previous accepted state.

Missing custom IRs must be restored or explicitly replaced. Frozen sound stays protected: restore its exact wet file or explicitly unfreeze it in Perform to allow rebuilding. Re-learning or choosing another IR can sound different and cannot recreate missing exported or Playlist files. A metadata-decode failure is reported separately; it cannot confirm intact edits, so retain the project and seek an earlier DAW project copy. Storage reports retained files and usage. The plugin keeps old recordings and renders because earlier DAW saves may still depend on them. Failed/cancelled copies preserve originals and complete backups; incomplete copies are not complete backups.

Troubleshooting and alpha limitations

Window size and UI scale

A fresh presentation profile opens at 900 × 600 logical pixels and 100% UI scale. Drag the window edge to add workspace, or open Settings → Appearance for 900 × 600, 1100 × 850, 1400 × 900 and 1600 × 1000 presets. UI scale offers 100% and 125% when they fit your display. Sizing adds workspace; UI scale magnifies controls and text; waveform zoom changes only the timeline view. At 125%, the minimum content occupies 1125 × 750 before host/window borders.

Size and scale are remembered locally for later openings, independently of your DAW project. Changing one editor does not resize another open instance. If a saved preference no longer fits, the editor temporarily fits the available work area while retaining that preference for a larger display. Non-fitting choices are unavailable. It never automatically shrinks below 100%; if even the minimum cannot fit, move to a larger work area or adjust host/display scaling. Owned Settings and Diagnostics windows use the chosen magnification and scroll when needed. Native file choosers retain their normal platform sizing. Physical DPI/host coverage remains limited to the recorded tests.

  • The plugin does not scan: confirm a Windows x64 VST3 host, the complete bundle and the chosen scan path. Avoid duplicate copies; preserve the old install before making changes.
  • No captured waveform: choose Learn, route audible audio through the insert, and start the DAW transport. Stop and wait for capture processing. Check inline status and Recapture audio.
  • Generate is unavailable: wait for capture/analysis, check Detect events, useful source and Default IR. Its disabled reason explains the current gate.
  • Audition is unavailable or silent: select a ready enabled swell, stop the DAW, check source/render readiness and Wet only/Live Wet settings. Check the normal output routing and start at low volume.
  • Export is unavailable: let preparation complete and resolve missing input/render notices. A previous file does not prove the current mix is ready.
  • Appearance differs: window size, display scaling and operating system can affect presentation. The images show a 1400 × 1000 native fixture, not a certified display-scaling matrix.
  • Alpha scope: unsigned Windows VST3, manual installation, no installer or code signing. DAW, clean-machine and accessibility coverage is limited to the sender's recorded tests. This guide does not promise compatibility beyond that evidence.

Investigate timing warnings

In a fixed-tempo project, a stable validated playback offset does not disable Snap. The editing grid stays anchored to captured timing when you press Play or Stop; existing source and swells do not move. A real change within the playback clock can still make Snap unavailable. Tempo automation requires separately supported mapping coverage; this fixed-tempo repair does not add tempo-map support.

If Snap becomes unavailable or prepared swells go silent during playback, preserve the project and captured assets before trying to repair it. Open Settings → Recovery → Open Diagnostics and use Copy diagnostics to retain the full report, including text outside the visible window. Copy while the symptom is happening before stopping or seeking, then copy again after Stop. The fixed-grid section explains Snap separately from wet playback admission. Live evidence identifies the run start, first timing rejection and preceding admitted callback when available. A stopped or available grid does not prove that wet played. Include these details with your build information; do not clear capture or regenerate merely to remove a timing warning. DAW offline rendering validates its own fixed-tempo run without moving accepted swell samples; genuine changes within that bounce still fail explicitly.

Appendix A. VCV Rack

  1. Load ReverbArise in VCV Host-FX. Add the VST3 search folder in Host-FX if needed. Patch stereo source audio into Host-FX and its stereo outputs into your audio output module. The Clocked examples use 48 kHz, 4/4 and 137 BPM.
  2. To assign a control input, right-click its label on Host-FX and choose the corresponding Note Gate. Patch the source pulse into that input. The rising edge sends the note. Keep the sound and control pulses on the same clock.

Learn in Rack

Song Mode

Song Mode needs the host to supply absolute musical position, tempo and meter. The Rack Host-FX setup here supplies beat pulses, so use Loop Mode to capture this source.

Loop Mode with Duration
  1. Patch one pulse per beat from the master clock to Clock B0 (23). In Learn, enable Loop Mode, select Duration, and set the number of bars or beats.
  2. Click Arm. Start the clock if it is stopped. The first pulse of a new clock run counts as beat one. With the clock already running, recording starts on the next bar line. Keep the clock running until the take is accepted.
Loop Mode with End on Signal

For a manual take, use the same Clock cable, select End on Signal, and click Arm. Recording starts on the next beat. Click Arm again during the last bar you want to record. Keep the clock running through the next bar line.

For a sequenced one-bar take, keep Clock connected and run a four-step sequence at one step per beat. Send Start/Arm C1 (24) on step 1 and Stop C♯1 (25) on step 4. Leave the Arm button off so the sequence starts the take. The next step 1 closes the capture. For a two-bar take, use eight steps and move Stop to step 8.

With Impromptu Clocked, patch Master to Clock, CLK 1 divided by 8 with zero delay to Start/Arm, and CLK 2 divided by 8 with a three-quarter-cycle delay to Stop. Start arrives on beat 1, Stop on beat 7 and the take closes on beat 9. Set stopped outputs to low and reset Clocked before pressing Run.

Loop Mode with End on repeat
  1. Patch one pulse per beat to Clock B0 (23) and a Step 1 pulse from each pass to Phrase C0 (12). The two pulses must arrive together at each repeat start. With Impromptu Clocked, use Master for Clock and zero-delay CLK 1 divided by 8 for a two-bar Phrase.
  2. Select End on repeat and click Arm. Keep the timing and audio running through two Phrase pulses. Capture starts at the first one after arming and ends at the next.

After a Loop is accepted, review the detected events and click Generate Swells. Enable Recapture audio before arming only when you want a successful new take to replace the accepted one.

Perform in Rack

Song playback

The Clock and Phrase cables cannot supply the song positions required for Song playback in this Rack setup. Use a captured Loop with the steps below for live wet swells.

Audition a swell

With a Loop accepted, open Perform, select a ready swell and use the Audition play button. The same button turns red and shows Stop while auditioning. Use Dry + wet to hear its captured context or Wet only to isolate the swell mix. Stop any active Loop playback before auditioning.

Cue and stop a Loop by hand
  1. Keep Clock connected and running. After generating swells, open Perform and enable Live playback in Settings. Match Rack's sample rate to the captured Loop.
  2. When Cue Loop shows Ready, click it. Beat one lands on the next bar line that leaves room for the full lead-in. Click Cancel Loop while it is waiting if you change your mind.
  3. Click Stop Loop to finish the current pass without the next lead-in. Click Stop Now while it is finishing for a short immediate fade. Choose Dry + Wet in playback settings to hear the live input alongside swells.
Cue and stop from a sequencer

Keep Clock connected. Patch separate trigger outputs to Cue E0 (16), Stop F0 (17) and Stop Now F♯0 (18) as needed. To align future cues to a sequencer phrase, send its Step 1 pulse to Phrase C0 (12) with a Clock pulse while the Loop is idle. Cue early enough to hear the full lead-in. After a clock loss or reset, restore timing and send a fresh Cue.

Hover over a disabled playback button for its reason. If the status asks for 44.1 kHz or another rate, set Rack to that rate to use the saved capture and swells.

Export a Loop from Rack

  1. Capture a Loop using any Learn method, then generate swells and wait for an enabled swell to be ready. Open Export. No additional control cable is needed; you can stop Clock while preparing the WAV.
  2. Choose Repeats, Lead-in grid and a Mix Character or Dry/Wet pair. Match Rack's audio rate to the captured rate to use Preview. The captured-rate WAV can still be saved when Preview is unavailable.
  3. Use Save WAV to a folder outside the plug-in's working storage, then import it into your destination DAW. Follow the placement instruction inside the tile. Use Wet Layer to add swells alongside the original dry; mute or replace the original dry for a dry-inclusive mix.

Appendix B. FL Studio

  1. Install the complete bundle into %PROGRAMFILES%\Common Files\VST3. In Plugin Manager, enable Verify plugins and Rescan previously verified plugins, then run Find installed plugins. Confirm the resolved bundle path.
  2. Load ReverbArise in the mixer insert receiving your source audio. Route the insert to your monitoring output. Use the supported Loop setup of 48 kHz and steady 4/4 timing. The FL Studio transport supplies timing for Learn and Perform.
  3. For MIDI control, add a MIDI Out channel on Channel 1 with a free port, such as 0. Set the effect wrapper's MIDI Input port to match. Put control notes in the MIDI Out Piano Roll and place that pattern in the Playlist. Manual capture and playback use the plug-in buttons without this route.

Learn in FL Studio

Song Mode from the Playlist
  1. Choose FL Studio's Song playback and open Learn with Loop Mode off. Start at the beginning of the Playlist or the first section you want to map.
  2. Play through the source audio and stop FL Studio to commit the captured ranges. Leave Recapture audio off to retain existing audio, or enable it before playing the range you want to replace.
  3. Review event markers, then click Generate Swells. With Generate on Stop enabled, Learn starts generation after a successful Song capture.
Loop Mode with Duration
  1. Select Song for the Playlist or Pattern for the selected pattern. In Learn, enable Loop Mode, select Duration and choose the length. For example, choose two bars and let a one-bar Pattern play twice to capture both passes.
  2. Click Arm and play. From a bar line, recording can start immediately. If playback starts or you arm mid-bar, capture waits for the next bar line. Let playback continue through the end of the take.

Set 2 Bars to capture two passes of a repeating one-bar pattern. FL Studio must report the repeat boundaries and keep playback continuous at each wrap.

Loop Mode with End on Signal

For a manual Playlist take, arm before the bar you want, then start or continue Song playback. Click Arm again during the last bar you want to keep. Recording closes at the next bar line while FL Studio is still playing.

In Pattern playback, the same manual stop can close at the pattern's declared wrap. For a one-bar pattern, arm before Play, then click Arm again during that bar and leave playback running through the wrap.

For MIDI control, leave Arm off. Put Learn Start/Arm C2 (24) at bar 3 beat 1 and Learn Stop C♯2 (25) at bar 4 beat 3 on the MIDI Out pattern. Start Song playback before bar 3 and let it run through bar 5 beat 1. The take contains bars 3 and 4.

Loop Mode with End on repeat
  1. Choose Pattern playback and select a whole-bar pattern. For Song playback, choose a Playlist repeat range that starts and ends on bar lines.
  2. Select End on repeat in Learn and click Arm. Play through a complete repeat. If you arm midway through a pass, capture waits for the next repeat to start and closes at the following boundary. A seek before the repeat ends cancels the take.

After any Loop capture method accepts the take, inspect the markers and click Generate Swells. Enable Recapture audio before arming only if you want to replace the accepted Loop.

Perform in FL Studio

Song playback and DAW rendering
  1. Open Perform with a prepared Song source. Enable Live playback in Settings and choose the routing you want. Start Song playback early enough to hear the lead-in to the first swell.
  2. Swells play at their saved Playlist positions. To include them in a normal FL Studio bounce, leave ReverbArise in Perform and render from FL Studio. Keep the song timing compatible with the capture.
Audition a Song or Loop swell

Stop FL Studio transport and stop any active Loop playback. Select a ready swell in Perform, choose Dry + wet or Wet only, and press the Audition play button. The same button turns red and shows Stop during playback in both Song and Loop Perform.

Follow a Pattern or Playlist repeat

Open Perform with an accepted Loop and prepared swells, enable Live playback, then press Play in FL Studio. Swells follow the repeat automatically when FL Studio reports a range matching the accepted Loop and no Playlist start is set. Use Stop Loop to finish the current pass or Stop Now for a short fade. Stop and restart the host transport to resume automatic playback.

Set a Playlist start

Park the Playlist playhead and click Set Loop Start. The saved bar and beat appear to the right of the button. Right-click the pair or press Shift+F10 on the button to enter a bar and beat manually or clear the start. Start FL Studio before the first swell to hear the full lead-in. The Loop repeats from the saved position until transport stops or you schedule a Stop. Use Stop Loop or the Stop MIDI note to finish the current pass, including its tail.

Cue and stop a Loop by hand

With no saved start or matching repeat, start transport and click Cue Loop when it is available. The Loop begins on the first eligible downbeat with room for the full lead-in. Click Cancel Loop while it is queued. After stopping transport or seeking, Cue again.

Sequence Cue and Stop from the Playlist
  1. Place Cue E1 (16) on the MIDI Out pattern before your target bar. For a two-bar Loop with at most two beats of lead-in, put Cue at bar 7 beat 3 to launch at bar 8 beat 1.
  2. Put Stop F1 (17) at bar 9 beat 3 to finish that pass at bar 10 beat 1. Use Stop Now F♯1 (18) for an immediate fade. Start Song playback before the first command you want to use.
  3. To shift the next launch off the Playlist bar line, send Phrase C1 (12) at the desired beat-one position while playback is idle, then Cue. Stopping or seeking restores the Playlist grid until a new Phrase arrives.

Use realtime playback for Loop wet. In the tested offline Loop bounce, FL Studio rendered the dry input. The current shared playback-note example has native processor coverage and awaits a desktop replay with the revised note map.

Export a Loop into the FL Studio Playlist

  1. Capture a Loop from Pattern or Song playback, generate swells, and select Export once an enabled swell is ready. You can stop FL Studio transport; export follows the captured Loop, not the current Playlist position.
  2. Set Repeats and Lead-in grid, choose Mix Character or the Dry/Wet levels, and check Preview. Keep the project tempo at the captured tempo for musical placement. Match the audio device rate to the captured rate when previewing.
  3. Drag the ready WAV tile into the Playlist, placing the file's beginning at the position shown by the placement instruction. For a four-bar lead-in and a desired Loop Bar 1 at bar 17, drop at bar 13. Use Save WAV and import the file if dragging is unavailable. Both delivery methods use the same prepared audio.
  4. Stay in Export while playing the delivered file so the plug-in does not add live swells again. With nonzero Dry in the WAV, mute or replace the original dry clip. Return to Perform when you want live swells instead of the delivered WAV.
