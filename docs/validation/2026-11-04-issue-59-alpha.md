Fixture audio passes the real capture/generation/render/export paths; images are not host screenshots or mockups.

Only a successful native invocation produces a capture receipt. The packager records source SHA, command and executable hash, decodes every required PNG, embeds it in User-Guide.html and inventories the HTML plus guide-provenance.json with all image hashes/dimensions. Fresh staging and the held build lock prevent reuse of an earlier capture. Missing/corrupt images, failed fixture readiness and mismatched source fail packaging. Screenshot provenance is generated in ignored output, avoiding a tracked self-referential commit hash.
