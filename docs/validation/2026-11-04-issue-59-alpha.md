## Native screenshot procedure

`scripts/release.ps1` runs the unchanged `scripts/build.ps1 -Configuration Release -Test`, reacquires its build-directory lock, verifies clean unchanged source and built identity, then runs `Release/preverb_learn_generation_ui_test.exe --guide-only` with `PREVERB_UI_M3_OUTPUT` set to a unique staging directory. This reuses `captureImage` / JUCE `createComponentSnapshot` in the existing production-editor test. Its four 1400 × 1000 images are empty Learn, captured Learn with markers, fully rendered Perform with the chronological first swell selected and Audition enabled, and prepared Export with Save/drag enabled. Fixture audio passes the real capture/generation/render/export paths; images are not host screenshots or mockups.

Only a successful native invocation produces a capture receipt. The packager records source SHA, command and executable hash, decodes every required PNG, embeds it in User-Guide.html and inventories the HTML plus guide-provenance.json with all image hashes/dimensions. Fresh staging and the held build lock prevent reuse of an earlier capture. Missing/corrupt images, failed fixture readiness and mismatched source fail packaging. Screenshot provenance is generated in ignored output, avoiding a tracked self-referential commit hash.
