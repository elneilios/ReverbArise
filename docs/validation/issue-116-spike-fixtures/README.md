# Issue #116 Rack spike sources

This is a source snapshot of the isolated experiments referenced by the [production handoff](../../development/loop-mode-production-handoff.md). It includes CMake targets, fixture generators, analyzers and measured summaries. Rack profiles, licensed modules, built VST3s, raw traces, WAVs and host logs remain local. Regenerate the VCV patches because they embed local plugin paths.

1. Build the repository’s Windows Release configuration using the repository wrapper and locate its matching JUCE source tree from the build cache.
2. Copy the contents of [rack](rack/) to the checkout’s ignored out/loop-mvp-spike/rack/ directory. Configure it as a standalone CMake project with JUCE_SOURCE_DIR set to the matching JUCE source and the native x64 MSVC toolchain. Use out/loop-mvp-spike/rack/build/ as its binary directory. These paths let the generators locate the Release VST3 bundles and let the optional offline wet harness find the compiled DSP libraries.
3. Use a disposable 48 kHz profile with Rack Free 2.6.6, licensed Host-FX 2.1.0, Fundamental 2.6.4 and Impromptu Modular 2.5.0 installed.

| Fixture | Build and run |
| --- | --- |
| CLKD capture boundaries | Build rack_clkd_trace_VST3 in Release. Run python clkd/make-fixture.py from the copied Rack spike root. Write any existing timing-*.csv names under traces/ to clkd/previous-traces.txt, one per line, or create an empty list. Open clkd/clkd-bar-stop.vcv and let it process for at least 75 seconds. Run python clkd/check.py. |
| CLKD cued playback | Build rack_clkd_cue_VST3 and rack_clkd_control_VST3 in Release. Run python clkd/make-cue-fixture.py. Record any existing clkd-cue-*.f32 names in clkd/previous-cue-traces.txt. Open clkd/clkd-cued-playback.vcv and wait for both completion sidecars, which require 96 seconds of VST3 processing. Run python clkd/check-cue.py. |
| Learn host smoke | Build the spike branch’s ReverbArise Release VST3. Run the capture fixture generator first, then python clkd/make-learn-fixture.py. Open clkd/ReverbArise-CLKD-Learn.vcv and use the two Learn capture methods. The patch loads the VST3 from the checkout’s Release build tree. |
| Earlier exact-period fixture | Follow the [original validation record](../2026-11-07-issue-116-rack-loop-timing.md). Some replay steps need the original local WAV or traces, or equivalent data generated by repeating the host checks. |

For [Host-FX input discovery](host-fx/RESULTS.md), copy [host-fx](host-fx/) into an ignored directory. Its CMake project supports the default automation probe, PROBE_MIDI_INPUT=ON for the Note Gate probe, and PROBE_CAPTURE=ON for the standalone recorder and native recorder test. Configure separate build trees using the directory names expected by make-matrix.ps1 and make-capture-fixtures.ps1. The original comparison patch and raw traces remain in the original workspace.
